# Private (members only)

Files in this folder stay in the private repository and are **never published to the website**. Only the `docs/` folder becomes the site.

Good uses: meeting notes, notes from calls with lenders or the lawyer, candidate properties, drafts not ready for the site.

Still keep these out of the repo entirely, even here: bank or account numbers, Social Security numbers, tax returns, credit reports, and anything a member hasn't agreed to share with the whole group. Use a private shared drive for those.

If you change the repository to public, everything in this folder becomes public too.
