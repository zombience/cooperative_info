# Member financial snapshot (template)

Each household fills this in **privately** first. Then the group decides what to share. **This repository and website are public.** Never commit filled-in copies. Keep them in a private shared drive.

The point is to find out early whether the plan fits everyone, rather than discovering it at closing.

| Question | Your answer |
|---|---|
| Cash I can put in at the start (without touching my emergency fund) | |
| Cash I could add later, and when | |
| Monthly housing cost I can carry comfortably | |
| Monthly housing cost I can carry at a stretch | |
| How long I expect to live here (best guess) | |
| How much I care about my share growing in value (1 = not at all, 5 = a lot) | |
| Could I qualify for a personal loan or share loan if needed? | |
| Would I be willing to lend money to the co-op beyond my share? How much? | |
| Things in the next 5 years that could change my plans (job, kids, partner, health) | |
| Dealbreakers | |

## Group discussion prompts
- Where are we far apart? Which differences can the structure absorb (unequal units, member loans), and which need a conversation?
- What happens if one person's answers change a year from now?
